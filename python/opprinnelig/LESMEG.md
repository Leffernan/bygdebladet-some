# Instagram-postar

Sjekkar bygdebladet.com kl. 06.00, 13.00, 17.00 og 21.30 og sender kvar ny sak som
ferdig Instagram-post (bilete + tekst) på e-post.

- Køyr manuelt: Actions → Instagram-postar → Run workflow
- Pause: Actions → Instagram-postar → «…» → Disable workflow
- Test lokalt: `python hent_saker.py --test` (legg postar i `ut/`, sender ikkje e-post)

Sjå brukarmanualen for meir.
